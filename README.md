# Bate-Papo Web — Node.js

Aplicação acadêmica de sala de bate-papo desenvolvida com Node.js e Express.

## Funcionalidades

- Cadastro de usuários
- Login e logout
- Sessão autenticada
- Envio de mensagens
- Listagem de mensagens
- Listagem de usuários
- Registro de último acesso com cookie
- Interface web servida pela pasta `public/`

## Stack

- Node.js
- Express
- express-session
- cookie-parser
- HTML
- CSS
- JavaScript

## Executando

```bash
npm install
npm start
```

A aplicação utiliza a porta `3000` no ambiente local.

## Observação de segurança

Este é um projeto didático: usuários e mensagens ficam em memória e a autenticação foi simplificada para estudo. Não é uma implementação pronta para produção.
